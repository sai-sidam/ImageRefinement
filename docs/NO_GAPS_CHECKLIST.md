# No-gaps checklist — June & Ember

**Purpose:** Your intention is the **best** outcome for June & Ember (best Instagram, best first post, best everything). “Best” means we consider **every angle** and leave **no gap**. This checklist is the reminder: before we ship any post, caption, prompt, strategy, or doc, we run through these angles. If we didn’t think about it, we’re not done.

Use this when:
- Creating or approving a post (image + caption + hashtags)
- Writing or updating a prompt or brief
- Deciding strategy (first post, content mix, tone)
- Adding or changing docs

## Pre-ship checklist (run before locking any post or strategy)

- [ ] **Customer:** We thought about what she wants or feels (not only what we want to say).
- [ ] **Empathy:** The message reflects that we understand her (moments, confidence, ease, trust).
- [ ] **Trust:** Image and copy feel real and consistent; no fake or misleading.
- [ ] **Brand:** On-brand (elegant, feminine, aspirational; warm; June & Ember).
- [ ] **Strategy:** Aligns with the goal for this asset (e.g. first post = launch + trust).
- [ ] **Creative:** Story, set, mood support “June & Ember is here” / arrival / aspirational but achievable.
- [ ] **Quality:** Image meets the bar (lighting, coherence, garment, no AI tells) if it’s a hero post.
- [ ] **Content:** Caption has a hook, CTA, and hashtags; format is correct (4:5, hero vs detail).
- [ ] **Clarity:** Obvious who we help and what we’re for.
- [ ] **No guess:** Gaps were filled with research or by asking, not by inventing.

If any box is unchecked, we’re leaving a gap. Fix it before we call it done.

---

## Process note (for AI and humans)

When the user says “do X,” the job is not only to **do X**. The job is to:

1. **Understand the intention** behind X (best outcome for June & Ember).
2. **Consider every angle** above — especially **customer** and **empathy**, which are easy to skip if not asked.
3. **Research** when we don’t know (web, docs); **ask** when we need a choice from the user; **don’t guess**.
4. **Then** do X — so the result is complete, not partial.
