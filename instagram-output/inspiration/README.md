# Inspiration library (scalable)

Per-brand folders for anything we save or record from our inspiration accounts. Use for format, captions, activity, reference images, or new use cases — add files as needed.

**Folders:** `ohpolly/`, `outcastclothing/`, `misscircle_newyork/`

**Examples of what to put here:**
- Reference images (screenshots, downloads) → use with `--reference-path=instagram-output/inspiration/ohpolly/hero-01.jpg`
- Caption samples → `caption-samples.txt` or `caption-samples.md`
- Activity notes (frequency, timing) → `activity-notes.md`
- Hashtag examples, Story notes, etc. → any filename that makes sense

**Index and “what we track”:** See [docs/INSPIRATION_FEED_AUDIT.md](../../docs/INSPIRATION_FEED_AUDIT.md). Update the per-brand section when you add or re-check; add new subsection or file type when you have a new use case.
